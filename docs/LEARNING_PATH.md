# Java 后端手敲路线（建议新聊天按一课一任务进行）

**总原则**：这个仓库是“答案对照版”，不是要你从头到尾机械抄一遍。请在电脑上新建另一个空目录自己做；每一课先讲原理、自己写、运行、排查，再打开参考代码比对。

1. **第1课：创建 Java / Spring Boot 空项目。** 理解 JDK、Maven、`pom.xml`、主启动类和包结构，启动一个空应用。只做这一步。
2. **第2课：第一个 Controller。** 手写 `GET /api/health`，用浏览器访问，理解 HTTP 请求到 Java 方法。
3. **第3课：城市与 List。** 创建 `City`，从内存集合返回 `/api/cities`；解释 `record`、构造器、泛型。
4. **第4课：Service 分层。** Controller 不写全部业务逻辑；写 `CityCatalog`，练依赖注入和异常。
5. **第5课：天气查询。** 先返回一份标记为 demo 的固定天气数据；再抽离 `WeatherDataSource` 接口。
6. **第6课：真实天气 API。** 调用 Open-Meteo，处理 JSON、超时、HTTP 错误；**不把假数据当真数据**。
7. **第7课：缓存与测试。** 先手写最简单的进程内缓存，学习 TTL、Junit 与接口测试。
8. **第8课：前端调用与独立挑战。** 一个页面调用 API；最后独立新增城市或一个天气字段，向老师讲清调用链。

如果你在公司电脑上练习，先遵守设备和安装政策；不要在未经批准的设备上安装软件或使用公司数据。个人项目使用个人电脑与公开天气数据即可。
